# open-tx-isp: where the driver differs from the vendor module

Items where the open kernel driver deliberately behaves differently from the
vendor `tx-isp-*.ko` (not bug fixes, which are in [CHANGELOG.md](../CHANGELOG.md)).
Each item names the switch that restores the vendor behaviour where one exists.

| Change | SoC | Default | Vendor behaviour back | Why | Status |
|---|---|---|---|---|---|
| No `dump_stack()` after level >= 2 ISP messages (`isp_printf`) | T21 | off | module parameter `warn_stack=1` (runtime, `/sys/module/tx_isp_t21/parameters/warn_stack`) | The vendor prints a full stack after every warning/error message: a console flood of about 100 ms per stack at 115200 baud, in ISP paths. The message itself is unchanged. | 2026-11-06, device A/B on cam-D (T21) |
| Bring-up trace parameters not built (`t20_trace`, `t20_runtime_trace` / `t10_runtime_trace`, `t20_trace_events`) | T10, T20 | not built | build with `TX_ISP_TRACE=y` | Not vendor parameters (our bring-up traces); about -10 KiB module RAM. Kernel 3.10 refuses to load a module given an unknown parameter, so no load script may pass them; none does (checked 2026-11-06: OpenIMP, the streamer, the thingino package and user overlay, `/etc/modules.d` on the T10/T20 test cameras). | 2026-11-06, device A/B on T10 and T20 |
| MSCA init stops with -1 on an allocation failure (`t32_msca_init`, `tx_isp_t32_msca_init.h`) | T32 | always | none | The vendor `tisp_msca_init` stores the NULL block, prints an error and runs `memset(NULL)` (kernel oops); the context allocation is never checked. | 2026-11-10, user OK; host oracle (vendor path checked separately), not device-tested yet (T32 port not on hardware) |
| MSCA scaler curve: input size 0 gives the ratio limit 27306 (Q14) instead of a division by zero (`t32_msca_curve_ratio`, `tx_isp_t32_msca_curve.h`) | T32 | always | none | With a zero size the vendor curve calculation divides by zero (hangs/traps). Non-zero sizes are bit-exact with the vendor. | 2026-11-10, user OK; host oracle (vendor path checked separately), not device-tested yet (T32 port not on hardware) |
| CLM `param_array_set` with zone count 0 returns -1 (`t32_clm_param_array_set`, `tx_isp_t32_clm.h`) | T32 | always | none | The vendor reads before its zone array when a parameter blob has 0 colour-temperature zones. Counts 1..64 are bit-exact with the vendor. | 2026-11-10, user OK; host oracle (vendor path checked separately), not device-tested yet (T32 port not on hardware) |
| LCE `lce_hist_method` clamps the ramp length n to 46 (`t32_lce_hist_method32`, `tx_isp_t32_lce.h`) | T32 | always | none | The vendor runs its ramp loop for n without a bound: from n = 36 it corrupts saved registers, from n = 45 its return address and from n = 47 its saved output pointer (crash). Only n <= 31 occurs on hardware. For n <= 46 the port reproduces the vendor output, including the spill of the first ramp into the second for n >= 32. | 2026-11-10, user OK; host oracle t32_lcet_oracle (n 0..46 vs the vendor C), not device-tested yet (T32 port not on hardware) |
| TSTP `tstp_mark1` stops at the 16-entry table (`tx_isp_t32_tstp.h`) | T32 | always | none | With a table longer than 16 entries the vendor runs off the end of its block and does not stop. Valid inputs are bit-exact with the vendor. | 2026-11-11, user OK; host oracle (vendor path counted, not compared), not device-tested (T32 port not on hardware) |
| RCFG / TSTP init skip the memset when the allocation failed (`tx_isp_t32_rcfgv.h`, `tx_isp_t32_tstp.h`) | T32 | always | none | The vendor memsets the NULL result of a failed allocation (kernel oops). Valid inputs are bit-exact with the vendor. | 2026-11-11, user OK; host oracle (vendor path counted, not compared), not device-tested (T32 port not on hardware) |
| Code-tuning open skips the memset when kmalloc failed (`tisp_code_tuning_open`, `tx_isp_t32_ctune.h`) | T32 | always | none | The vendor memsets the NULL result of a failed kmalloc. Valid inputs are bit-exact with the vendor. | 2026-11-11, user OK; host oracle (vendor path counted, not compared), not device-tested (T32 port not on hardware) |
| LCE simd_v4 refuses par[12] > 18 or par[13] > 32 (`t32_lce_v4`, `tx_isp_t32_lce.h`) | T32 | always | none | The vendor runs past its 576 tiles; above 32 columns its loop never ends. Valid inputs are bit-exact with the vendor. | 2026-11-11, user OK; host oracle (vendor path counted, not compared), not device-tested (T32 port not on hardware) |
| ISP-core ioctl returns 'unported' for a NULL subdev at index >= 2 (`tx_isp_t32_ispioctl.h`) | T32 | always | none | The vendor dereferences the NULL subdev. Valid inputs are bit-exact with the vendor. | 2026-11-11, user OK; host oracle (vendor path counted, not compared), not device-tested (T32 port not on hardware) |
